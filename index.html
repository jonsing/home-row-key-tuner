Home-row Shift tuner

Records how you really type, then runs the recording through a port of the Dygma Fast Superkeys (Qukeys) firmware logic to see which settings would have produced a false Shift or missed one.

Set up Bazecor before capturing

The capture needs your raw key presses. While a and ; are Superkeys the keyboard sends Shift instead of the press itself, so turn them into plain keys on a test layer first. Your Superkeys and their settings stay as they are.

  1. Make a test layer. In the Layout Editor, select an unused layer, open its layer menu and choose Copy from layer. Pick the layer you normally type on.
  2. Put plain keys on the home row. On the test layer, click the a Superkey and assign the plain A key. Do the same for ;. Leave all other keys alone.
  3. Save. Click Save changes.
  4. Switch to the test layer. Use a layer key, or set it as Default layer under Keyboard Settings → General while you capture.
  5. Check it. Hold a for a second in the field below, then ;. Both should repeat like normal letters.
    a: not tested ;: not tested

While you type

  • For a capital, hold a or ; exactly like your home-row Shift, then press the letter. The page uses the text to tell which presses were meant as Shift.
  • Typos are fine. The cursor waits for the right key, so just keep going.
  • Use the USB cable if you can. Wireless adds jitter to the timings.
  • Esc ends a session early and saves it.

When you're done

Switch back to your normal layer, and reset Default layer if you changed it.

Press "Start session", then type the text that appears here. Esc finishes early.
